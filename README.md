# FrameFlow

Interactive Sliding Window Protocol Learning Lab.

## Features

- Go-Back-N and Selective Repeat learning/comparison
- Configurable window size and total frames
- Manual, random, or no frame loss
- Slow / Default / Fast playback
- Previous Step / Next Step / Auto Play
- Sequence numbers and protocol state
- Waiting-for-ACK visualization
- Retransmission and loss statistics
- Efficiency measurement
- Experiment history
- Efficiency graph
- Theory/terminology reference
- Step explanations and event log

## Run

Open `index.html` with VS Code Live Server or directly in a browser.

## Note

This is a protocol simulator/learning tool, not a real packet transmission implementation.
